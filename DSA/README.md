# 🚀 DSA Practice – Java

A structured collection of **Data Structures and Algorithms implemented in Java**, created to strengthen problem-solving skills, understand algorithmic concepts, analyze complexity, and prepare for technical coding interviews.

This repository documents my **day-by-day DSA learning journey**, starting with fundamental searching and sorting algorithms and gradually progressing toward advanced data structures and algorithmic techniques.

The purpose of this repository is to:

- Build a strong foundation in Data Structures and Algorithms

- Understand how algorithms work internally

- Improve logical and problem-solving skills
- Practice writing clean and maintainable Java code
- Prepare for technical interviews and coding assessments
- Track continuous DSA learning progress

# 📊 Algorithm Complexity

| Algorithm | Best | Average | Worst | Space |
|-----------|------|---------|-------|-------|
| Linear Search | O(1) | O(n) | O(n) | O(1) |
| Binary Search | O(1) | O(log n) | O(log n) | O(1) |
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |

> **Note:** Complexity can vary depending on the specific implementation and optimization used.
